# GitHub Clone — Build & Collaborate

A feature-rich, high-performance GitHub clone built with modern web technologies. This project replicates the core GitHub experience, allowing users to browse repositories, manage issues, and explore code in a responsive, dark-themed interface.

##  Current Status: Active Development
The project is currently in the **MVP (Minimum Viable Product)** phase. Core navigation and repository structures are implemented, with enhanced UI/UX features being added daily.

###  Key Features
- **Modern Tech Stack**: Built with **React 19**, **Vite**, and **Tailwind CSS**.
- **Responsive Design**: Mobile-first approach with a sleek dark mode.
- **Interactive UI**: Powered by **Radix UI** and **Lucide Icons** for a premium feel.
- **Developer Tools**: Integrated with **ESLint**, **Vitest**, and **GitHub Calendar** components.

##  Technology Stack
- **Frontend**: React, Tailwind CSS, Vite
- **Components**: Radix UI, Lucide React, Primer Octicons
- **Routing**: React Router DOM 7
- **Testing**: Vitest & React Testing Library
